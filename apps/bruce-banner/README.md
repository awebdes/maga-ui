# Bruce Banner

Промо-баннеры для приложения Ipoteka Bank (слот 328×106) на русском, узбекском и английском. Для команд, которые не дизайнеры: описал баннер словами — AI написал тексты на трёх языках и подобрал иллюстрацию, проверил в телефоне, скачал ZIP. Собран на Maga UI, рядом с Kiln.

Перенос старого Bruce Banner (Toolcraft, React): 15 официальных шаблонов, слои, темы, шрифт Squad. Старый рендер повторён пиксель в пиксель (135 из 135 рендеров), потом исправлены его ошибки — см. «Отличия от старого».

## Запуск

```bash
cd apps/bruce-banner
npm install
npm run vendor     # шрифты, картинки и слайс старого движка с bruce-banner.vercel.app
npm run dev        # localhost:5173
```

`vendor` нужен один раз: брендовые файлы (Squad — лицензионный шрифт Fontfabric, PNG принадлежат банку) не лежат в git, пока репозиторий публичный. Без них приложение запускается и пишет об этом.

Без ключа Gemini AI работает в демо-режиме: варианты — ближайшие официальные шаблоны с их текстом, «Перевести» и «Короче» честно говорят, что это демо, иллюстрация — заготовка. Ключ — в `.env.local` (см. `.env.example`).

## Как устроено

| Где | Что |
|---|---|
| Старт | «Какой баннер нужен?» и примеры брифов; «Мои баннеры»; 15 шаблонов в реальном размере 328×106 по группам; «Открыть файл баннера» (`.banner.json`, можно перетащить) |
| Варианты AI | Три баннера по брифу, сразу на RU/UZ/EN, с иллюстрациями из библиотеки. Язык переключается для всех трёх. Под каждым — что не влезает или перекрывается. «Ещё варианты», «Взять этот» |
| Слева вверху | К началу, имя баннера, отменить / вернуть |
| Сверху | Сохранено · AI (подключён / демо / выключен) |
| Справа вверху | Превью в телефоне (P), Экспорт (E), настройки: фокус на баннере, углы как в приложении, меньше анимации, «Как пользоваться» (тур из 5 шагов, сам открывается при первом баннере), код доступа к AI, скрыть панели (H) |
| Слева | Слои: имя, глаз, красная точка у сломанного. «+» — текст, бейдж, иллюстрация, курс, свечение |
| Справа | Свойства выделенного. Ничего — тема, раскладка, языки, имя. Текст — поля RU / UZ / EN со статусом, подсказка, если текст плохо читается на фоне, ✨ Короче / Иначе / Перевести, кегль, цвет. Иллюстрация — библиотека, «Мои картинки» (нарисованные и загруженные в любом баннере этого браузера), своя картинка, ✨ Нарисовать, размер, наклон, отражение. Карта, логотип, бейдж, курс — свои |
| Снизу | Язык RU · UZ · EN с точкой состояния, «Все языки» (L), ✨ Перевести с основного языка на остальные. Над ним — «UZ написан AI — проверьте» |

**Сцена.** Клик выделяет верхний слой под курсором: картинки — по непрозрачным пикселям, текст — по строкам, а не по всей ширине колонки (иначе заголовок перехватывает бейдж рядом с короткой строкой). Тащить — двигать со снэпом к полям 16 px, центру и краям других слоёв, Shift — по одной оси, Alt — без снэпа. Углы масштабируют, ручка сверху поворачивает (Shift — шаг 15°), Esc отменяет жест. Двойной клик по тексту открывает поля всех языков прямо под ним. Что вылезает за слот, видно полупрозрачным «призраком».

**Языки.** Язык на экране — состояние вида, не документа: в отмену не попадает. Точка у языка: зелёная — всё влезает; жёлтая — предупреждение (бейдж закрывает текст, в AI-тексте цифры, которых нет в брифе); красная — текст не влезает или нет заголовка. Контраст меряется по пикселям: баннер рисуется без текстов, под строками сравнивается цвет фона с цветом текста; ниже 2.4:1 — подсказка в свойствах текста, экспорт она не останавливает (у одобренных шаблонов она не загорается). Длинный текст сначала уменьшается до 13 px, потом считается «не влезает». В узбекском `o'`, `g'` и похожие апострофы сами становятся `‘`. Текст от AI помечен, пока человек его не поправил или не нажал «Проверено». Ответ AI, пришедший после ручной правки того же языка, отбрасывается.

**AI.** Сервер — четыре функции (`server/handlers.ts`), их вызывают адаптеры Vercel (`api/ai/*`), dev-middleware Vite и unit-тесты.

| Эндпоинт | Что делает |
|---|---|
| `POST /api/ai/brief` | Бриф и каталог раскладок (лимиты символов меряются настоящим шрифтом) → три варианта: раскладка, тема, тексты RU/UZ/EN, иллюстрация из библиотеки, подсказка «что нарисовать» |
| `POST /api/ai/text` | Короче / иначе / перевести / поправить один слот |
| `POST /api/ai/illustration` | Предмет → PNG на ровном `#FF00FF`; фон вырезается в браузере, в воркере |
| `GET /api/ai/status` | Подключён ли ключ, какие модели, нужен ли код |

- Gemini Interactions API, `store: false` на каждом запросе, ответ строго по JSON-схеме; всё, что вне каталога, сервер выбрасывает. Проверено живым ключом 17.10.2026: бриф → 3 варианта за ~5 с, «Короче» и «Перевести» — за ~3 с, иллюстрация — за ~15 с.
- Текстовые модели по умолчанию долго «думают» (до 3 тыс. токенов размышлений на ответ в три слова, 24 с; размышления оплачиваются как ответ). Поэтому `thinking_level: low`; `minimal` для `gemini-3.8-flash` не поддерживается. Если модель из env не знает `thinking_level`, запрос повторяется без него.
- «Короче» и «Иначе» не добавляют того, чего нет в тексте и брифе («онлайн», «бесплатно», «мгновенно»).
- В промпте: голос банка (коротко, выгода первой, без «!» и капса), UZ латиницей с `‘`, **цифры только из брифа**.
- Модели меняются через env без кода.
- Доступ: тот же сайт или разрешённый origin, код команды (`BANNER_ACCESS_CODES`, вводится один раз и хранится в браузере), лимит в минуту на адрес. Лимит в памяти функции — best effort; настоящий потолок — квота и бюджетный алерт в Google Cloud.

**Вырезка фона** (`src/app/chroma.ts`):
1. Картинки приходят только в JPEG, а фон модель рисует светлее заказанного `#FF00FF` (около `#FC39FB`), поэтому цвет фона меряется по краю кадра. Край должен быть ровным вокруг этого цвета и пурпурным; если нет (модель нарисовала пол или градиент), один автоповтор.
2. Альфа по «избытку пурпура» `(min(r,b) − g) / max(r,b)` как доле избытка самого фона: 1 на фоне, ≤ 0 на зелёном, оранжевом и белом. Почти прозрачное становится прозрачным совсем, иначе шум JPEG превратился бы в дымку.
3. Край объекта (полупрозрачное кольцо и крайний непрозрачный ряд, куда JPEG подмешивает фон) красится цветом объекта чуть глубже; у тонких деталей без «глубины» фон размешивается `(I − (1−α)·K) / α`. Остаток розового убирается только в краевой полосе — фирменный оранжевый не трогается.
4. Обрезка по объекту.

Новая картинка встаёт туда, где была видна старая: у библиотечных PNG широкие прозрачные поля, поэтому вписывается в непрозрачную часть, а не в рамку.

**Превью.** Android 360×800 с вырезом под камеру, рамка на CSS. Слот 328 = 360 − 2×16, баннер 1:1, рядом выглядывают соседние баннеры карусели, свайп работает. Язык переключает и баннер, и весь экран приложения. L — по телефону на язык. Баннер перелетает из редактора в слот (FLIP); с «меньше анимации» — просто появляется.

**Экспорт.** Превью каждого включённого языка с его проблемами. Размеры: @1x / @2x / @3x (328×106 … 984×318) или 4096×1324, как в старом. PNG или JPG. ZIP: `bruce-banner_<имя>_<язык>@<n>x.png` и `texts.txt` с текстами по языкам. Пустой заголовок и «не влезает» останавливают ZIP до подтверждения; контраст и предупреждения — нет. Перед рендером дожидается шрифтов и картинок.

**Хранение.** Всё в IndexedDB этого браузера: список, документы, картинки (по SHA-256, без дублей), миниатюры, «Мои картинки» (40 последних нарисованных и загруженных не удаляются, даже если ни один баннер их не использует — иллюстрация от AI стоит денег). Автосохранение через 500 мс после правки. `.banner.json` переносит баннер к коллеге вместе со своими картинками. Safari чистит хранилище сайта после 7 дней без визитов — для важного держите файл баннера.

**Горячие клавиши** (по физической клавише — работают и на русской раскладке): ⌘Z / ⇧⌘Z, Delete, стрелки (Shift ×10), `[` `]` поворот, ⌘D дублировать, 1 / 2 / 3 язык, L все языки, Enter редактировать текст, P превью, E экспорт, H скрыть панели, Esc отменить жест / снять выделение.

**Устройство.**
- `src/engine/` — движок без DOM: документ, шаблоны, темы, `layout()` (одна функция для рендера, рамок, попадания, снэпа и проверок), рендер на Canvas 2D, проверки, операции, история.
- `src/app/` — редактор: стор с жестами (`change` / `begin` / `live` / `end`, как в Kiln), сцена, манипуляции, острова, AI-флоу, хранение, экспорт.
- `src/preview/` — телефон и экран приложения.
- `server/` — AI: хендлеры, клиент Gemini, промпты, схемы, моки.
- `src/ui/kit/` — копия кита Kiln плюс Prompt и Drop.

## Отличия от старого Bruce Banner

Режим `compat` повторяет старый рендер для проверки паритета. Обычный режим исправляет:

- **Экспорт был резче редактора.** Старый экспорт масштабировал контекст, а размытие свечения и теней — нет, поэтому в 2K/4K-файлах glow и тени заметно резче, чем на экране. Новые файлы совпадают с превью. Свечение в них будет мягче, чем в старых экспортах.
- Логотипы Visa и Mastercard больше не сплющены.
- Трекинг учитывается при переносе строк.
- Свечение рисуется одинаково во всех браузерах (erf-градиент вместо `ctx.filter`).
- Подпись берёт цвет темы.
- Добавлены автоуменьшение длинного текста и предупреждения о перекрытии.
- Бейджи под заголовком (Oddiy) больше не уезжают за нижний край: в UZ и EN заголовок уменьшается, чтобы они влезли.

Найдено в официальных шаблонах:
- В UZ «Кредит до 100 млн» и «Пустой блок — кредит» бейдж «2 daqiqa ichida» закрывает вторую строку заголовка. В старом приложении так же. Теперь горит жёлтая точка.
- Ассеты `card-humo-a` и `card-humo-b` названы наоборот: `a` — карта Humo, `b` — Uzcard. Шаблоны используют их так же, как старые, оставил как есть.

## Что зафейкано

- **Экран приложения в превью** — реконструкция по токенам дизайн-системы (`#52AE30`, `#2F7D1A`, `#2A2B2E`, `#5D6168`, фон `#F6F7FA`, Source Sans 3), а не копия продакшна. Радиус маски слота (12 px) — допущение.
- **AI без ключа** — моки (`server/mock.ts`). С ключом — настоящий Gemini, проверен живьём.
- Размеры для разработки и CMS неизвестны, поэтому два пресета.
- Формат только 328×106. Командной библиотеки нет: всё в браузере.

## Проверки

```bash
npm test              # vitest: шаблоны, раскладка, проверки, операции, вырезка фона, сервер на моках, схемы, имена файлов
npm run typecheck     # клиент и сервер
npm run build
npm run e2e:parity    # 15 шаблонов × 3 языка × ×1/×2/×3 против старого движка, пиксели
npm run e2e:app       # редактор: тур, текст, переполнение, ⌘Z на русской раскладке, драг, контраст, ZIP, превью, автосейв
npm run e2e:ai        # AI на моках: варианты, рисование и вырезка, «Мои картинки», поздний ответ, код доступа, ошибки
npm run e2e:fonts     # 45 официальных текстов с настоящими шрифтами, глифы Squad и Source Sans 3
node tests/e2e/shots.mjs   # скриншоты в docs/screens/
```

E2E и паритет требуют `npm run vendor`. Скриншоты лежат в `docs/screens/` локально: на них брендовые картинки, в git они попадут вместе с брендовыми файлами, когда репозиторий станет приватным.

## Деплой

Vercel, корень проекта — `apps/bruce-banner` (`vercel.json`: Vite, функции `api/ai/*`). Пока брендовых файлов нет в git, сборка сначала скачивает их со старого bruce-banner.vercel.app (`npm run vendor`), поэтому старый деплой нельзя удалять, пока файлы не попадут в репозиторий.

| Env | Зачем |
|---|---|
| `GEMINI_API_KEY` | Ключ из проекта Google Cloud **с включённым биллингом**: на бесплатном уровне Google может использовать данные для улучшения продуктов, а в брифах будут невыпущенные ставки |
| `GEMINI_TEXT_MODEL`, `GEMINI_IMAGE_MODEL` | Модели, по умолчанию `gemini-3.8-flash` и `gemini-nano-banana-2.1` |
| `GEMINI_STYLE_REFS` | `1` — отправлять три брендовые иллюстрации как референс стиля |
| `BANNER_ACCESS_CODES` | Коды команд через запятую. **Ставить обязательно**: без кода функции открыты любому, кто знает адрес |
| `BANNER_ALLOWED_ORIGINS` | Другие сайты, которым можно звать API |
| `AI_MOCK` | `1` — демо-режим даже с ключом |

Стоимость ([pricing](https://ai.google.dev/gemini-api/docs/pricing), на 16.10.2026):
- бриф → 3 варианта на `gemini-3.8-flash` — около $0.01;
- иллюстрация 1K на `gemini-nano-banana-2.1` — $0.0336, на `gemini-3-pro-image` — $0.134.

У моделей картинок нет бесплатного уровня. Поставьте дневную квоту image-запросов и бюджетный алерт в Google Cloud.
