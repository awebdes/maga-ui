Maga UI · v0.1 prototype

Quiet chrome, loud object.

Components for interfaces where one thing on screen matters and everything else serves it. Controls live in small glass islands at the edges, step back when you stop moving, and answer every touch with motion.

One focal objectThe center owns color and motion. Chrome stays grey until you touch it.
Chrome is glassIslands blur what is behind them, so light from the object and the bloom tints them.
Every touch answersPress scales down, release springs back, overdrag rubber-bands. Nothing snaps without easing.

Buttons

One light button per screen at most. The juice variant is for the action the whole screen exists for.

Juice hero action
Hover charges it blue and lights the bloom behind nearby glass. Click Enhance to see the busy state: progress fills the button and the width stays put.
Primary · Cell · Ghost · Clear
Cell is the default. Ghost for reversible actions, Clear inside islands that already have a fill.
Icon buttons rest · on · disabled · juice
40px square, 14px radius. Every icon button has a tooltip with its shortcut.
